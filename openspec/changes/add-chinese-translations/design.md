## Context

项目当前仅有英文文档，希望添加中文翻译支持。这是一个内容层面的国际化(i18n)需求，不需要修改现有代码架构。

## Goals / Non-Goals

**Goals:**
- 建立统一的中文翻译文件命名规范
- 确保翻译文件与原文保持同步更新
- 保留原文内容，便于对照阅读

**Non-Goals:**
- 不实现自动翻译（机器翻译）
- 不修改现有英文文档结构
- 不添加多语言切换的动态功能

## Decisions

1. **文件命名规范**: 采用 `原文件名.zh-CN.md` 格式
   - 理由：与常见的国际化文件命名方式一致（如 i18n、l10n），`.zh-CN` 明确标识语言和区域

2. **翻译格式**: 在翻译文件中保留原文，后续跟翻译内容
   - 理由：便于用户对照理解，不改变原有阅读习惯
   - 格式示例：
     ```
     ## English Title
     English content here.

     ## 中文标题
     中文翻译内容。
     ```

3. **优先级策略**: 优先翻译用户面向的核心文档
   - README.md → README.zh-CN.md
   - 主要指南文档

## Risks / Trade-offs

- [风险] 翻译内容可能过时
  - 解决：在 PR 审查时确保英文和中文版本同步更新
